# SIMULATING — What If… 15 Mind-Bending Scenarios

A colorful, responsive website containing the 15 video ideas from the supplied PDF. The wording of the source ideas, premises, thumbnail text, and science twists is preserved verbatim.

The website includes search and copy buttons for each idea and a complete collection copy action.

The site is deployed to GitHub Pages using the workflow in .github/workflows/pages.yml.
